# Security Policy

`@runqora/sdk` runs inside other people's servers, and the Better Auth plugin
can read and manage their users. Security reports are taken seriously and
handled first.

## Reporting a vulnerability

Do not open a public issue, discussion or pull request for a suspected
vulnerability.

Use GitHub's private vulnerability reporting: the **Report a vulnerability**
button on this repository's **Security** tab. Include:

- the affected function, entry point and version,
- steps to reproduce, and a minimal proof of concept where it helps,
- what an attacker could do with it.

Leave out real credentials, access tokens, personal data and anything taken
from a production system.

We will acknowledge the report, investigate its impact, and coordinate a fix,
a release and its disclosure with you. Please give us a reasonable time to fix
the issue before publishing any details.

## Supported versions

Fixes are released for the latest version of `@runqora/sdk`. Problems in the
hosted service at runqora.dev can be reported the same way.
